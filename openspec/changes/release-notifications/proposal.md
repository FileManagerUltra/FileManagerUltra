# Release notifications and Windows application identity

Check published stable GitHub Releases at startup without delaying the window or
opening a modal dialog. Offer a dismissible notification and a download button
that opens the release page for manual installation. Add a manual Help command
and an opt-out preference. Embed the application icon in the Windows executable
so installed shortcuts use the correct icon.

In-app downloads, executable replacement, automatic restarts and update signing
are out of scope for this first version.
